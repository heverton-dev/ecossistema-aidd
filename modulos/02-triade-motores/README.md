# Domínio 02 — Tríade de Motores

Fatia vertical canônica de fabricação de software e fluxos de geração do Ecossistema AIDD.

## Responsabilidades
- Fluxo 01 Pure (`aidd-pure`): geração do zero com TDD rigoroso Red-Green e arquitetura PWA.
- Fluxo 02 Open (`aidd-open`): composição e integração de software open-source curado.
- Fluxo 03 Freedom (`aidd-freedom`): libertação de dependências proprietárias e migração low-code.
