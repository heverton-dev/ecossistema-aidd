# Domínio 04 — Núcleo Compartilhado

Fatia vertical canônica do kernel de utilitários, CLI unificada e contratos centrais do Ecossistema AIDD.

## Responsabilidades
- Roteamento fino de comandos CLI e orquestração de sub-rotinas comuns.
- Contratos de dados, schemas JSON e protocolos de handoff universais.
- Scripts determinísticos de manipulação de AST, Git e filesystem.
- Portões canônicos de integridade estrutural e saída binária.
