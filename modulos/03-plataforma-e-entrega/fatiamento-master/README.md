# Fatia — Fatiamento Master

Monólito modular em fatias verticais (VSA) com Clean Architecture e gates anti-atalho.

- Criação e montagem de módulos (`aidd-master add-module`).
- Harmonização do Quarteto Sine Qua Non (`/swagger`, `/webhooks`, `/mcp`, `/docs`).
- Interface pública da fatia: `interface.py`.
