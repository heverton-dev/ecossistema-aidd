# Domínio 03 — Plataforma e Entrega

Fatia vertical canônica responsável por fatiamento de meso-camada, blindagem enterprise e operações de infraestrutura.

## Responsabilidades
- Fatiamento e orquestração de branchs/worktrees em pipeline (`aidd-master`).
- Injeção determinística de componentes e blindagem de segurança (`aidd-enterprise`).
- Empacotamento de infraestrutura, VPS sizing, Docker e orquestração Cloudflare (`aidd-ops`).
