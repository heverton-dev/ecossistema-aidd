# Comando /generate (nome antigo)

Apelido de 1 ciclo para o motor do Fluxo 01. Use `/pure` (fluxo completo) ou `python ecossistema.py pure-motor "<ideia>"` (só o motor de 8 fases).

## Uso:
`/generate <ideia>`

## Ação:
Executa a skill `aidd-pure`, seção "Engine only".
Equivalente CLI: `python ecossistema.py pure-motor "<ideia>"` (o antigo `python ecossistema.py generate "<ideia>"` ainda funciona e avisa "nome antigo").
