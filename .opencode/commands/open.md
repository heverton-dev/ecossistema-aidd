# Comando /open

Dispara o Fluxo 02 (`aidd-open`) da Tríade Canônica: criação acelerada integrando motores open-source robustos em fatias verticais VSA.

## Uso:
`/open <nome_do_projeto> [dominio]`

## Ação:
Executa a esteira síncrona completa:
`[FORGE -> PLANNER] -> FACTORY -> [MASTER -> ENTERPRISE -> OPS]`
com curadoria de engines open-source, gateways FastAPI e orquestração Docker Compose.

Equivalente CLI:
`python ecossistema.py run-fluxo --fluxo open --nome "<nome>" --slug <slug> --dominio <dominio> --pasta ./projetos/<slug>`
