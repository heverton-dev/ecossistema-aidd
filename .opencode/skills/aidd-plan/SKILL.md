# AIDD Plan — Gerador Estrutural de Planos (/plan)

Contrato executável universal do comando `/plan <nome>`. Estrutura planos fatiados determinísticos em `docs/planos/<nome>/`.

## Como Usar

No chat do assistente:
```text
/plan <nome_do_plano>
```

Via CLI Central:
```bash
python ecossistema.py plan init <nome_do_plano>
```
