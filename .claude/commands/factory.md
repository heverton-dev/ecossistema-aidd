# Comando /factory (nome antigo)

Apelido de 1 ciclo para o motor do Fluxo 02. Use `/open` (fluxo completo) ou `python ecossistema.py open-motor` (só o gerador da stack multi-serviço).

## Uso:
`/factory --plano <caminho_do_plano> --pasta <pasta_destino> [argumentos...]`

## Ação:
Executa a skill `aidd-open`, seção "Engine only".
Equivalente CLI: `python ecossistema.py open-motor <args>` (o antigo `python ecossistema.py factory <args>` ainda funciona e avisa "nome antigo").
