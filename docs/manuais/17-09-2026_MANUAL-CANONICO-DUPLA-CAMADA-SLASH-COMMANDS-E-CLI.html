A Arquitetura de Dupla Camada

Eliminando o abismo entre experiência humana sem fricção e rigor determinístico de engenharia de software.

1. O Princípio da Dupla Camada Universal

💬 CAMADA 1: Zero Fricção Humana

Slash Commands / Chat

Projetada para que qualquer usuário (de não-técnico ou júnior a PhD) interaja sem precisar memorizar sintaxes ou flags de terminal.

  • /planner "Quero um sistema de logística CTT com frotas"
  • /generate "App de e-commerce do zero puro"
  • /factory --plano ./PLANNER.json --pasta ./minha-stack

⚙️ CAMADA 2: Engenharia Determinística

CLI & Quality Gates

Execução binária via terminal `ecossistema.py`. Garante zero stubs, validação AST, contratos estritos e testes reais com saída binária (exit 0 / exit 1).

  • python ecossistema.py planner init --fluxo 1 --nome "CTT"
  • python ecossistema.py planner validate ./PLANNER.json
  • python ecossistema.py planner audit ./meu-app

2. Matriz Canônica de Ferramentas & Casos de Uso

Fundação & Governança

1. aidd-forge

Pre-Commit Hooks & AGENTS.md

💬 Camada 1: Slash Commands (Chat)

Injeta e repara governança sem fricção:

/forge /forge ./meu-projeto

⚙️ Camada 2: CLI & Gates

Comandos formais e validação das 15 regras (G01-G15):

python ecossistema.py forge init <pasta> python ecossistema.py forge audit <pasta>
Combustão Primária (SDD/BDD)

2. aidd-planner

Gera PLANNER.json

💬 Camada 1: Slash Commands (Chat)

Intake socrático em linguagem natural:

/planner "Quero um app de rastreamento CTT" /planner 1 "Criar MVP de pagamentos do zero" /planner 2 "Hub WhatsApp com Evolution API"

⚙️ Camada 2: CLI & Gates

Geração, validação e exportação de schemas:

python ecossistema.py planner init --fluxo 1 --nome "App" --pasta ./app python ecossistema.py planner validate ./app/PLANNER.json python ecossistema.py planner audit ./app
Fluxo 01: Do Zero Puro

3. aidd-generator

Pipeline 8 Fases TDD

💬 Camada 1: Slash Commands (Chat)

/generate "Sistema de agendamento de consultas" /generate --fases 1,2,3 "Módulo de faturamento"

⚙️ Camada 2: CLI & Gates

python ecossistema.py generate "Ideia" G_TESTES_REAIS (pytest Red-Green + AST anti-stubs)
Fluxo 02: Open-Source

4. aidd-factory

Gateway VSA & Docker Stacks

💬 Camada 1: Slash Commands (Chat)

/factory --plano ./PLANNER.json --pasta ./stack /factory "Adicionar Redis e RabbitMQ ao stack"

⚙️ Camada 2: CLI & Gates

python ecossistema.py factory --plano <arq> --pasta <dest> G_FACTORY_COMPOSE, G_FACTORY_INTEGRATION (6 Gates)
Fluxo 03: Desacoplamento Low-Code

5. aidd-bridge

Anti-Lockin Lovable/v0

💬 Camada 1: Slash Commands (Chat)

/bridge scan ./app-lovable /bridge convert-db ./app-lovable --saida ./db

⚙️ Camada 2: CLI & Gates

python ecossistema.py bridge pack ./app --dest ./prod G_BRIDGE_SCAN (Verificação estrita anti-lockin)
Harmonização Monólito Modular

6. aidd-master

Vertical Slice Architecture (VSA)

💬 Camada 1: Slash Commands (Chat)

/master init ./meu-monolito /master add-module frotas

⚙️ Camada 2: CLI & Gates

python ecossistema.py master add-module <modulo> G_MASTER_ISOLATION & Testes unitários da fatia
Missão Crítica & Resiliência

7. aidd-enterprise

Blindagem Criptográfica SHA-256

💬 Camada 1: Slash Commands (Chat)

/enterprise inject component circuit_breaker /enterprise audit

⚙️ Camada 2: CLI & Gates

python ecossistema.py enterprise inject skill auth G_ENTERPRISE_INTEGRITY (Validação Hash SHA-256)
Infraestrutura, Segurança & Deploy

8. aidd-ops

SSH Determinístico & Uptime Kuma

💬 Camada 1: Slash Commands (Chat)

/ops "Deploy da app CTT na VPS 192.168.1.10 com SSL" /ops init-vps

⚙️ Camada 2: CLI & Gates

python ecossistema.py ops "<requisitos>" --pasta <dest> G_INFRA_COMPOSE, G_HADOLINT (Melhores práticas OCI)
