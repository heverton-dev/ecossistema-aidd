Os 10 Avanços da Reestruturação DDD / Clean Architecture

Implementados, testados e mesclados em main no commit fa8c070:

ITEM 01

Fonte Única do Núcleo Compartilhado

Criada a pasta canônica componentes/compartilhado/src-core/. Foram eliminados 27 arquivos duplicados manualmente entre aidd-master e aidd-enterprise, saneando 3 divergências silenciosas que existiam entre eles.

componentes/compartilhado/src-core/
ITEM 02

Unificação de Orquestradores Duplicados

Consolidação do pipeline no aidd-generator (pipeline_completo vs pipeline_prefect) e no aidd-ops (pipeline_ops vs pipeline_ops_deploy) em fontes canônicas únicas.

tools/aidd-generator/src/ · tools/aidd-ops/src/
ITEM 03

CLIs como Cascas Finas Orientadas a Casos de Uso

O arquivo monolítico scripts/aidd.py caiu de ~1.160 linhas para ~260 linhas no aidd-master e no aidd-enterprise. Toda regra de negócio foi extraída para Use Cases testáveis em application/commands/.

tools/aidd-master/scripts/aidd.py · application/commands/
ITEM 04

Pacote Formal com Importação Lazy no Generator

Removidos os atalhos frágeis de sys.path.insert no carregamento de fases, transformando o pipeline em um pacote formal Python com resolução robusta e importação lazy.

tools/aidd-generator/pipeline_phases/
ITEM 05

Contrato Formal JSON Schema entre Ops e Master/Enterprise

Criado schema JSON versionado para o plano de infraestrutura gerado pelo aidd-ops e consumido pelos projetos, eliminando convenções soltas e premissas implícitas.

schemas/plano_infraestrutura.schema.json
ITEM 06

Módulo de Referência (modulo1) em Clean Architecture / DDD

Reescrita completa do módulo de referência em 4 camadas rigorosas: domain/ (entidades puras), application/ (casos de uso), infrastructure/ (persistência SQLite) e interfaces/ (rotas e controllers).

tools/aidd-master/src/modules/modulo1/
ITEM 07

Gate Mecânico de Arquitetura AST (G_ARQUITETURA_DELIVERABLE)

Auditor estático automático que inspeciona a AST do código gerado para impedir SQL fora de infraestrutura, acoplamento de banco em rotas e imports de infraestrutura dentro de entidades de domínio.

gates/G_ARQUITETURA_DELIVERABLE.py
ITEM 08

Scaffolders Atualizados para Criar DDD de Fábrica

Os comandos de criação de novos módulos no Master e Enterprise já geram as 4 camadas por padrão, com testes automatizados assegurando que nenhum módulo novo nasce fora da convenção.

tools/aidd-master/scripts/add_module.py
ITEM 09

Autocorreção Arquitetural na Fase 08 do Generator

O pipeline autônomo agora submete cada arquivo gerado à auditoria estática de camadas. Caso seja detectada violação, um laço corretivo intervém para refatorar o código antes da gravação final.

tools/aidd-generator/pipeline_phases/fase_08_deliverable.py
ITEM 10

Testes de Integração Reais para o Helm Chart do Ops

Implementada suíte de testes de integração reais para o Helm chart gerado pelo aidd-ops, validando que a infraestrutura provisionada sobe e opera de verdade.

tools/aidd-ops/tests/test_helm_integration.py

Problemas Pré-Existentes Rastreáveis (Sem Maquiagem)

Questões herdadas que foram documentadas com transparência durante os trabalhos e que permanecem mapeadas para a próxima fase:

HERDADO

Teste do aidd-generator commita projeto real no git sob certas condições

Efeito colateral não-hermético de teste identificado durante execuções automatizadas: um dos testes de geração dispara comando de git commit na árvore do monorepo. O teste está mapeado para isolamento em sandbox temporária.

tools/aidd-generator/tests/
HERDADO

Runner legado G_TESTES_REAIS apresenta contaminação de processos

Ao executar os testes das 5 ferramentas em um único interpretador Python sequencial, há resíduos em memória e imports cruzados gerando falsos negativos. As suítes executadas via pytest individual passam 100% (1.864 passed).

gates/G_TESTES_REAIS.py
HERDADO

6 pontos residuais de sys.path.insert em scripts auxiliares

O carregamento principal de fases do generator foi saneado com pacote formal, mas 6 scripts auxiliares pontuais ainda utilizam manipulação manual de path por dependerem de padronização na CLI.

scripts auxiliares de aidd-generator
