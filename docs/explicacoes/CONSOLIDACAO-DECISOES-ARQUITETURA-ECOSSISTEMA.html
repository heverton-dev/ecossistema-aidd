2. Cibersegurança & Defesa em Profundidade

Padrão bancário e corporativo contra as ameaças do OWASP Top 10.

OWASP A03 / A07

Queries Parametrizadas & Auth

Proibição absoluta de interpolação de strings em SQL. Todas as consultas utilizam prepared statements parametrizados. Senhas cifradas com Argon2id/bcrypt e salt individual.

✓ Zero SQL Injection garantido em repositórios
ANTI-TIMING ATTACKS

HMAC SHA-256 em Tempo Constante

Webhooks e tokens validados estritamente com hmac.compare_digest para anular vulnerabilidades de canal lateral (side-channel timing attacks).

✓ Assinaturas criptográficas invioláveis
ZERO PLAIN-TEXT SECRETS

Cofre Assimétrico `sops + age`

Nenhuma variável de ambiente sensível reside em texto claro. Criptografia assimétrica de curva elíptica X25519; chaves privadas isoladas e deciframento estritamente em memória.

✓ Repositório seguro contra vazamento de chaves
INTEGRIDADE ESTRITA

Blindagem SHA-256 Anti-Tampering

Componentes e templates de segurança enterprise possuem manifestos de checksum SHA-256. Se um único byte for adulterado, o gate bloqueia a esteira com Exit 1 imediato.

✓ Código imutável contra adulterações
LGPD & GDPR COMPLIANT

Trilha de Auditoria com `trace_id`

Identificador universal X-Trace-Id em todas as requisições. Logs estruturados com ofuscação automática de PII (dados pessoais mascarados).

✓ Rastreabilidade total e respeito à privacidade
CONTAINER SECURITY

Hadolint & Usuário Não-Root

Gate G_HADOLINT audita todos os Dockerfiles. Execução mandatória como USER appuser, imagens Alpine minimalistas e pinning estrito de versões.

✓ Superfície de ataque de container minimizada

4. O Monólito Modular Canônico

Fatias Verticais de Domínio (VSA) apoiadas em uma Camada Horizontal Compartilhada.

↕
Eixo Vertical de Domínio

Vertical Slice Architecture (VSA)

Cada regra de negócio é isolada em seu próprio diretório em features/ (ex: encomendas, frotas, entregas):

  • • routes.py: Endpoints FastAPI tipados com Pydantic
  • • services.py: Lógica de negócio pura sem acoplamento externo
  • • repositories.py: Queries parametrizadas anti-SQL injection
  • • models.py: Entidades e schemas específicos da fatia
  • • tests/: Testes de integração isolados da feature
↔
Eixo Horizontal Compartilhado

Cross-Cutting Concerns (`core/` / `shared/`)

Infraestrutura centralizada e segura consumida por todas as fatias:

  • • Database Engine: Pool de conexão assíncrono e transações
  • • Security Vault: Gestão de segredos e sanitização de dados
  • • Telemetry: Logs estruturados e rastreabilidade via trace_id
  • • Resilience: Circuit Breakers, Retries e Rate Limiters globais
  • • Event Gateway: Mensageria interna para eventos assíncronos

6. A Tríade Canônica de Criação & Entrega

Forge dita as regras, o Pré-Plano alinha a intenção, e o desenvolvedor escolhe o motor de construção.

FLUXO 01 • DO ZERO PURO

aidd-generator

Pipeline determinístico em 8 fases guiado por TDD Red-Green. Constrói código 100% proprietário sem motores pré-existentes.

Ideal para negócios sob medida
FLUXO 02 • MOTORES OPEN-SOURCE

aidd-factory

Alavancagem sobre software livre consolidado (filas, bots, mensageria). Gera as fatias VSA de integração e orquestra containers.

Ideal para velocidade com Open-Source
FLUXO 03 • LOW-CODE DESATADO

Todos os 3 fluxos convergem obrigatoriamente para: aidd-master (VSA + Horizontal) ➔ aidd-enterprise (SHA-256 + Resiliência) ➔ aidd-ops (VPS SSH + sops/age + Kuma).
