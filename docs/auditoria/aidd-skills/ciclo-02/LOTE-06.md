## 3. Achados no código, fora do escopo deste lote

1. **`aidd-frontend-forms` contradiz a Lei #11.** O corpo (título, `## Overview`, `description`) diz "Next.js ... aligning with Ecosystem Law #11", mas a Lei #11 do `AGENTS.md` define TanStack Start como stack Padrão-Ouro e declara o Next.js abolido. O lote só acrescentou um guardrail (sem `next/*` em apps do ecossistema); reescrever descrição e corpo fica para um ticket próprio.
2. **`aidd-mcp` aponta para uma fonte vazia.** O protocolo manda escrever em `componentes/<scope>/mcps/<name>/server.py`, mas `componentes/compartilhado/mcps/` só tem `.gitkeep`; os servidores reais (`cloudflare-mcp`, `docker-mcp`, `mcp-verificador-cve`) moram em `tools/aidd-ops/mcps/` e `tools/aidd-pure/mcps/`. Ou os servidores migram para `componentes/`, ou o protocolo da skill muda.
3. **`aidd-components` diz "sync never deletes", mas o código já poda.** `sync()` em `scripts/gestor_componentes.py` remove arquivos que saíram da fonte dentro de um componente-pasta (`_remover_sobras_diretorio`, coberto por `gates/test_gestor_componentes_drift.py`). Só pastas inteiras de componente renomeado não são removidas. A frase do corpo deve ser precisada.
