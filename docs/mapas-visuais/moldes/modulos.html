Mapa dos Módulos VSA

Depois da migração VSA, o código do ecossistema mora em modulos/<área>/<fatia>/. Este mapa mostra cada área, as fatias dentro dela, as ferramentas que moram em cada fatia (segundo o MAPA-DONOS-FERRAMENTAS.json) e quantos guardas e arquivos Python cada uma tem.

Regra de Montagem

Como as Áreas se Organizam

Área

Pasta de primeiro nível em modulos/; a descrição é a primeira frase do README.md dela.

Fatia

Subpasta de uma área. Pode abrigar ferramentas (aidd-*), guardas (gates/) ou contratos.

Fronteira

Uma fatia não importa o interior de outra; o que é compartilhado mora no núcleo compartilhado.
