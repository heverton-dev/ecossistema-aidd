Mapa visual · peças: MCP (telefone) e hook (alarme)

Mapa das conexões

Duas peças que ligam o agente ao resto do mundo. O MCP é um telefone para fora: dá ao agente uma ferramenta que mora em outro programa. O hook é um alarme: toca sozinho num momento combinado, sem ninguém pedir.

O quê · onde mora

Os três tipos de conexão

MCP que o agente usa

Registrado em .mcp.json (e nas configs dos outros harnesses). Vem de fora e é registrado com dependencia add-mcp, nunca copiado. Skill: aidd-dependencies.

MCP de uma ferramenta

Mora dentro da ferramenta (tools/<f>/mcps/) e vai junto com o app que ela gera. Não é para o agente deste repositório usar, por isso não aparece nas configs. Skill: aidd-mcp.

Hook

Configurado em .claude/settings.json: um evento (PreToolUse, SessionStart…), um filtro e o comando que roda.

Quando

Quando criar cada uma

MCP

  • o agente precisa de um serviço de fora (documentação, navegador, GitHub): registre um MCP de terceiro;
  • o app gerado precisa expor uma ferramenta própria: crie um MCP dentro da ferramenta, com fonte em componentes/;
  • segredo nunca vai no arquivo: só o nome da variável de ambiente.

Hook

  • algo precisa acontecer sempre num momento, sem depender de o agente lembrar;
  • se a regra só precisa ser conferida no commit, é guarda no pre-commit, não hook;
  • o hook precisa ser rápido e não pode travar a sessão se a ferramenta dele faltar.
