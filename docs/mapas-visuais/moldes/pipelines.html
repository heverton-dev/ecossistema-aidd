Mapa dos Pipelines

Um pipeline é a ordem fixa em que as peças trabalham. Este mapa mostra cada fluxo da Tríade (etapas e chamada de CLI por fluxo, lidas do scripts/orquestrador_sincrono.py), as cadeias declaradas nas skills (Step N of the … flow) e as skills que rodam um pipeline próprio, com as etapas do respectivo SKILL.md.

Regra de Montagem

De Onde Vem Cada Pipeline

Tríade

Um pipeline por fluxo (pure, open, freedom). As etapas são os métodos etapa_NN_* do orquestrador; a chamada é a do ramo daquele fluxo.

Cadeias de skills

Skills cuja descrição diz Step N of the <x> flow formam uma cadeia, na ordem de N (ex.: melhoria → plan → orchestrate).

Skills de pipeline

Skills que run the … pipeline: as etapas são os títulos ### Phase N ou os itens numerados da seção Execution/Steps/Workflow/Protocol.
