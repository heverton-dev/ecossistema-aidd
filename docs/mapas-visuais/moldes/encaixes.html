Protocolo de Engenharia

Procedimento para Implementação de Novos Encaixes

  1. Reaproveitamento de Esquemas.Verifique previamente se algum contrato existente já comporta os campos demandados antes de introduzir nova especificação.
  2. Especificação em JSON Schema.Formalize o esquema em componentes/compartilhado/specs/<de>-to-<para>.schema.json, declarando propriedades obrigatórias e tipos estritos.
  3. Validação na Barreira de Entrada.O módulo receptor deve validar os dados contra o schema antes do processamento, abortando com erro sob qualquer não-conformidade.
  4. Comprovação Ativa (Lei #13).Implemente teste automatizado fornecendo carga útil corrompida para atestar que a barreira rejeita dados fora de contrato.
  5. Auditoria de Integração.Execute python scripts/catalogo_pecas.py para validar a compatibilidade da nova chamada contra as assinaturas das ferramentas.
