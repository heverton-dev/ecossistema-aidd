Mapa Visual · Atalhos Operacionais (Comandos Slash)

Mapa dos Comandos Slash

Os comandos slash constituem atalhos ergonômicos disponíveis nas interfaces de chat dos agentes (ex.: /pure, /melhoria, /plan). Atuam como despachantes determinísticos que invocam a respectiva skill especializada. Este mapa cataloga os comandos configurados e audita o vínculo formal entre cada atalho e seu procedimento canônico correspondente.

{{TOTAIS}}
Conceito e Finalidade

Relação entre Comandos e Procedimentos

Definição Formal

Arquivo padronizado em componentes/compartilhado/comandos/<nome>.md, distribuído deterministicamente para as pastas de comandos de cada harness via components sync.

Ergonomia Semântica

Permite acionamento intuitivo com nomenclaturas em português (ex.: /melhoria), direcionando a execução para a skill subjacente em nomenclatura canônica inglesa (aidd-improvement).

Desacoplamento e Apontamento

O comando declara unicamente o direcionamento para a skill aidd-*, abstendo-se de replicar instruções operacionais ou parâmetros internamente.

Protocolo de Engenharia

Procedimento de Criação de Comandos

  1. Consulta Prévia.Inspecione o catálogo para confirmar se a skill já possui atalho correspondente registrado.
  2. Declaração Canônica.Crie o arquivo em componentes/compartilhado/comandos/<nome>.md, documentando o propósito e inserindo a declaração formal Executa a skill `aidd-<assunto>`.
  3. Sincronização e Validação.Execute python ecossistema.py components sync --tipo command e confirme conformidade via components verify com exit 0.

Convenção oficial: docs/protocolos/CONVENCAO-AUTORIA-SKILLS.md, seção 5.3.
