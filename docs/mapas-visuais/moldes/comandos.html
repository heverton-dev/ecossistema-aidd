Mapa dos comandos slash

Um comando slash é o botão que você aperta no chat: /pure, /melhoria, /plan. Ele não faz o trabalho sozinho; só chama a skill certa. Este mapa mostra todos os comandos e qual skill cada um chama.

O quê · por quê · para quê

O botão e o manual

O que é

Um arquivo em componentes/compartilhado/comandos/<nome>.md, distribuído para todos os harnesses pelo components sync.

Por que existe

O nome que as pessoas digitam pode ser em português (/melhoria), enquanto a skill tem nome em inglês (aidd-improvement). O comando liga um ao outro.

A regra

O comando só aponta para a skill aidd-*; ele nunca copia o conteúdo dela. A regra oficial está na convenção de autoria de skills.

Como

Como criar um comando

  1. Procure antes.Se um comando abaixo já chama a skill, não crie outro com outro nome.
  2. Escreva o arquivo.componentes/compartilhado/comandos/<nome>.md, com o uso e a frase Executa a skill `aidd-<assunto>`. É por essa frase que este mapa descobre qual skill o comando chama.
  3. Distribua.python ecossistema.py components sync --tipo command e depois components verify, com exit 0.

Regra oficial: docs/protocolos/CONVENCAO-AUTORIA-SKILLS.md, seção 5.3.
