Mapa visual · peça: script (máquina sem cérebro)

Mapa dos scripts

Um script é uma máquina sem cérebro: faz um trabalho mecânico, sem LLM. Os de scripts/ servem o ecossistema inteiro. Este mapa mostra cada um, o que faz e quem o chama, para achar as máquinas que ninguém liga.

ecossistema.py: o script vira um comando que você digita.

O commit

.pre-commit-config.yaml ou .githooks/pre-commit: roda sozinho a cada commit.

Guardas e outros scripts

Um guarda ou outro script importa o módulo. "Quem chama" é medido por nome citado no código, então é uma aproximação.
