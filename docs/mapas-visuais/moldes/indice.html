Estado de Sincronização dos Mapas

A situação de cada mapa é auditada deterministicamente contra o repositório. O status Concluído certifica que o artefato em disco reflete com precisão os dados atuais do catálogo factual. Desatualizado indica divergência entre o arquivo gerado e alterações recentes no catálogo. A criar sinaliza componente previsto com molde e gerador pendentes de implementação.

Governança Técnica

Arquitetura de Compilação dos Mapas

Molde Estrutural

docs/mapas-visuais/moldes/<tipo>.html: template semântico em HTML que define layout e seções fixas com marcadores dinâmicos.

Gerador Determinístico

scripts/mapa_visual.py: rotina determinística em Python que preenche os marcadores com dados extraídos do catálogo.

Catálogo Factual

docs/auditoria/mapa-pecas/catalogo-pecas.json: base factual de verdade gerada por scripts/catalogo_pecas.py sem interferência manual.

O procedimento detalhado de autoria e atualização encontra-se documentado na Parte 9 do Manual de Montagem e na skill canônica aidd-visual-maps.

Compilado por scripts/mapa_visual.py indice. Procedimento de atualização completa: execute python scripts/catalogo_pecas.py, seguido de python scripts/mapa_visual.py <tipo> para cada mapa e, por fim, python scripts/mapa_visual.py indice.
