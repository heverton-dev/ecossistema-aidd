Mapas do ecossistema

Um mapa por tipo de peça. Cada um mostra tudo o que existe hoje daquele tipo e ensina a construir uma peça nova sem repetir as que já existem. Esta página lista todos os mapas que o ecossistema precisa ter e o estado real de cada um.

Os mapas

O estado não é marcado à mão. Concluído quer dizer que o arquivo existe e está igual ao que o gerador produz hoje a partir do catálogo. Desatualizado quer dizer que o arquivo existe, mas o catálogo mudou depois dele. A criar quer dizer que o mapa ainda não tem molde e gerador.

Como

Como um mapa é feito

Molde

docs/mapas-visuais/moldes/<tipo>.html: o texto fixo em português, com marcadores onde entram as listas.

Gerador

scripts/mapa_visual.py: uma função por mapa, que preenche cada marcador a partir do catálogo.

Dados

docs/auditoria/mapa-pecas/catalogo-pecas.json, gerado por scripts/catalogo_pecas.py. Nada da lista é escrito à mão.

O passo a passo está na parte 9 do manual de montagem e, para o agente, na skill aidd-visual-maps.

Gerado por scripts/mapa_visual.py indice. Para atualizar tudo: python scripts/catalogo_pecas.py, depois python scripts/mapa_visual.py <tipo> para cada mapa e, por último, python scripts/mapa_visual.py indice.
