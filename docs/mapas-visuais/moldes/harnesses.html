Mapa visual · peça: harness (o programa que roda o agente)

Mapa dos harnesses

Um harness é o programa onde o agente trabalha: Claude Code, OpenCode, Cursor, Gemini CLI e outros. Cada um lê as peças de uma pasta própria. Este mapa mostra cada harness, que tipos de peça ele recebe e para onde cada uma é copiada.

{{TOTAIS}}
A regra

Uma fonte, muitas cópias

Fonte única

Toda peça nasce em componentes/. Nenhuma pasta de harness é editada à mão.

O entregador

python ecossistema.py components sync --tipo todos copia cada peça para o destino de cada harness, seguindo gates/manifesto_harnesses.json.

Quem confere

components verify, G_HARNESS_COMPAT e G_UNIVERSAL_HARNESS exigem cópia idêntica em todos. O sync nunca apaga: peça renomeada precisa sair de todos os destinos.
