Mapa dos Ambientes de Execução (Harnesses)

O harness é o ambiente de tempo de execução onde o agente opera (Claude Code, Antigravity, OpenCode, Cursor, Gemini CLI, entre outros). Cada harness requer árvores de diretórios e convenções de configuração próprias. Este mapa inventaria os ambientes suportados, cataloga as regras de distribuição e audita a paridade de componentes em cada destino.

{{TOTAIS}}
Diretriz Arquitetural

Princípio de Fonte Única e Distribuição Agnóstica

Fonte Canônica Única

Todos os ativos reutilizáveis são geridos exclusivamente em componentes/compartilhado/. Nenhuma pasta de harness deve ser manipulada diretamente.

Distribuidor Determinístico

O utilitário python ecossistema.py components sync --tipo todos propaga os componentes segundo as rotas mapeadas em gates/manifesto_harnesses.json.

Portões de Paridade

Os comandos components verify, G_HARNESS_COMPAT e G_UNIVERSAL_HARNESS auditam a identidade bit a bit entre os destinos, prevenindo divergências entre ferramentas.
