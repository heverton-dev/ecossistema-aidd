Mapa dos Agentes

Os modelos de agente (templates/agents/*.md) vão junto com o app gerado e dizem a cada subagente o que ele faz. Este mapa lista cada modelo, em que ferramentas ele aparece e se as cópias são idênticas: a versão é uma letra por conteúdo (mesma letra, mesmo arquivo byte a byte).

Regra de Montagem

Como Ler as Versões

Modelo

Um nome de arquivo em templates/agents/ dentro de modulos/03-plataforma-e-entrega/.

Cópia idêntica

O mesmo modelo em mais de uma ferramenta com a mesma letra: candidato a fonte única.

Versões diferentes

Mesmo nome com letras diferentes: o comportamento do agente depende de qual ferramenta entregou o app.
