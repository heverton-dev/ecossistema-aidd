O que é uma ferramenta

O que é

Uma pasta em tools/aidd-<nome>/ com código, testes, guardas próprios e um AGENTS.md com as regras dela. Ela é chamada por python ecossistema.py <nome> ....

Por que existe

Cada etapa da Tríade precisa de uma fábrica que faça uma coisa só, bem feita, e que dê para testar sozinha.

O que não é

Não é skill: a skill é o manual que ensina o agente a usar a ferramenta. Não é guarda: o guarda confere o que ela produziu.

Quando

Quando criar, e quando não

Crie quando…

  • uma etapa da receita não tem ferramenta nenhuma (veja o mapa dos encaixes);
  • um trabalho novo tem entrada e saída bem definidas e dá para testar isolado.

Não crie quando…

  • outra ferramenta já tem um comando com o mesmo trabalho (veja os verbos repetidos abaixo);
  • a ideia é copiar arquivos de outra ferramenta: chame a original, não duplique.
Como

O que toda ferramenta precisa ter

  1. Pasta e descrição.tools/aidd-<nome>/ com um README.md cuja primeira citação (>) diz o que ela faz. É dali que este mapa tira a descrição.
  2. Botão no painel.Um comando em ecossistema.py que chama a entrada de CLI da ferramenta, com --help que responda.
  3. Testes reais.Uma pasta tests/: o guarda G_TESTES_REAIS roda o pytest de cada ferramenta em todo commit que toca tools/.
  4. Manual para o agente.Uma skill aidd-<nome>, seguindo a convenção de autoria de skills.
  5. Disciplina de teste.Toda mudança em tools/<nome>/ registra a execução real em docs/teste-end-to-end/relatorio-teste-end-to-end.md (Lei #9, conferida pelo G_DISCIPLINA_TESTE_FERRAMENTA).
