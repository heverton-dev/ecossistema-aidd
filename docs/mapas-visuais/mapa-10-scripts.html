Mapa de Scripts e Automações Determinísticas

Os scripts representam automações determinísticas estritas, executadas sem intervenção de modelos de linguagem (LLM). Os utilitários localizados em scripts/ atendem a todo o ecossistema. Este mapa consolida a finalidade operacional de cada script e suas respectivas fontes de acionamento, identificando rotinas sem referências ativas.

Mecanismos de Invocação de Scripts

Interface Unificada (CLI)

ecossistema.py: o script é disponibilizado como comando executável via console.

Gatilhos de Git Hooks

.pre-commit-config.yaml e .githooks/pre-commit: execução automatizada na validação de cada commit.

Chamadas Internas e Quality Gates

Invocação direta por quality gates ou scripts integradores. O rastreamento de referências é inferido a partir de citações estáticas no código-fonte.
