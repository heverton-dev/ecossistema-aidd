Mapa de Distribuição para os Ambientes (Harnesses)

Diferentes assistentes de inteligência artificial trabalham em bancadas diferentes (Claude Code, Google Antigravity, Cursor, OpenCode). Para não termos que redesenhar as ferramentas para cada bancada, mantemos uma matriz central: quando alteramos uma peça na gaveta principal, ela é copiada de forma idêntica para todas as bancadas com um único comando.

{{TOTAIS}}
A Regra da Fonte Única

Nunca Mexa na Cópia da Bancada

1. A Matriz Original

Todas as habilidades, comandos e especificações originais residem exclusivamente em componentes/compartilhado/. É ali que qualquer melhoria deve ser feita.

2. O Distribuidor Automático

O comando python ecossistema.py sync atua como uma esteira distribuidora que carimba e replica as peças para as pastas de cada assistente (.claude/, .agents/).

3. Proibido Desgarrar da Matriz

Se alguém editar uma cópia local diretamente, o guarda de integridade detecta a divergência e acusa erro, garantindo que ninguém trabalhe com ferramentas desatualizadas.
