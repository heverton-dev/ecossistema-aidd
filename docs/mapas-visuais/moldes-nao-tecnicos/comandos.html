Mapa dos Comandos Rápidos (Slash Commands)

Os comandos rápidos (como /pure, /freedom, /melhoria ou /plan) são como os botões de atalho no painel da cabine de comando. Quando você digita uma barra acompanhada do nome, o assistente sabe exatamente qual manual puxar da gaveta e qual máquina acionar sem que você precise digitar instruções longas e cansativas.

A Fiação do Painel

Como o Botão se Conecta à Ferramenta

1. O Clique no Teclado

Você digita o atalho no chat (por exemplo, /open ou /diagnose). Esse comando funciona em qualquer ambiente de desenvolvimento suportado.

2. O Fio até a Skill

Cada botão está ligado a uma habilidade correspondente em componentes/compartilhado/skills/, que instrui o agente sobre como proceder de forma disciplinada.

3. A Saída no Terminal

O assistente então aciona a ferramenta ou o script no terminal através do comando unificado python ecossistema.py <ação>, executando o trabalho real.
