Mapa dos Scripts e Automações Determinísticas

Um script é como um robô mecânico de linha de produção industrial: ele não tem cérebro artificial, não sonha nem tem imaginação, mas aperta parafusos e monta engrenagens com precisão matemática absoluta. Sempre que você alimenta o robô com a mesma peça, ele devolve exatamente o mesmo resultado, sem oscilações nem alucinações.

Quem Aperta o Botão de Ligar

As Três Fontes de Acionamento dos Robôs

1. O Painel Principal (CLI)

Você digita no terminal através do comando unificado python ecossistema.py <ação> para acionar a rotina diretamente.

2. A Cancela do Commit

O gatilho de pré-commit aciona o script automaticamente para inspecionar cada pedaço de código antes de autorizar a gravação.

3. Os Fiscais e Outros Robôs

Um guarda de qualidade ou outro robô da fábrica convoca o script para realizar um cálculo ou conferência estrutural rápida.
