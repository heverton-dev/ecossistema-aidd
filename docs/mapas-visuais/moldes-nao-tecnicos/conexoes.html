Mapa de Conexões Externas e Sensores de Borda

Para construir sem ficar isolado em uma ilha, o ecossistema usa dois tipos especiais de fios: os MCPs (que funcionam como uma linha direta de telefone para consultar serviços externos, nuvens e bancos de dados) e os Hooks (que são como sensores de presença que apitam quando o agente vai fazer um movimento arriscado).

Como Cada Canal de Comunicação Opera

O Telefone Externo (MCP)

O agente precisa ver o mapa de código, consultar a documentação na nuvem ou acessar o banco? Ele levanta o fone do MCP. Cada servidor externo é catalogado formalmente no arquivo .mcp.json com verificação de segurança.

O Sensor de Alarme (Hook)

É uma tranca automática no ciclo de trabalho. Se o agente tentar executar um comando perigoso ou esquecer de rodar a validação antes de commitar, o sensor dispara, a esteira trava e o assistente é avisado antes de cometer um erro.
