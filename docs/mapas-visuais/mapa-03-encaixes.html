Mapa dos encaixes

Um encaixe é o formato combinado entre duas peças: o que uma entrega e a próxima recebe. Este mapa mostra a receita da Tríade etapa por etapa, cada chamada que uma etapa faz a uma ferramenta e se ela encaixa de verdade, e os contratos que ligam as etapas.

O quê · por quê · para quê

Por que o encaixe importa

O que é

Duas coisas: a chamada (o comando exato que a receita manda para a ferramenta) e o contrato (o arquivo JSON Schema que diz o formato do que passa de uma etapa para a outra).

Por que conferir

Uma chamada com uma opção que a ferramenta não conhece faz a etapa quebrar na hora de rodar, mesmo que cada peça, sozinha, funcione.

Para que serve

Para ver onde a receita quebra antes de rodar, e para uma peça nova saber exatamente o formato que precisa entregar.

A receita · etapa por etapa

As etapas da Tríade e suas chamadas

Cada chamada foi conferida contra a ajuda real da ferramenta (os subcomandos e as opções que ela aceita). encaixa quer dizer que a ferramenta aceita a chamada como está escrita; quebra quer dizer que não aceita.

Como

Como criar um encaixe novo

  1. Procure antes.Se um dos contratos acima já leva o dado que você precisa, acrescente o campo nele em vez de criar outro.
  2. Escreva o contrato.Um JSON Schema em componentes/compartilhado/specs/<de>-to-<para>.schema.json, com os campos obrigatórios marcados.
  3. Valide na passagem.A etapa que recebe confere o arquivo contra o schema antes de trabalhar, e para com erro se não bater. Conferir e deixar passar é fachada.
  4. Prove que morde.Um teste que entrega um arquivo fora do formato e exige a reprovação.
  5. Confira a chamada.Rode python scripts/catalogo_pecas.py: ele confere cada chamada da receita contra a ferramenta, e este mapa mostra o resultado.
