# Plan: `forge audit` & `forge conform` — Compliance Auditing for Existing Projects

## Context

The 13-09-2026 audit reports documented a manual process: reading governance files, checking 20+ compliance items, measuring token footprint, and applying surgical fixes. This process took hours of AI agent time. We need to automate it as two new forge commands:

- `forge audit [path]` — scans an existing project and produces a compliance report
- `forge conform [path]` — applies automated fixes for detected gaps

## Phase 1: Audit Engine (`core/audit_engine.py`)

### Data model

```python
@dataclass(frozen=True)
class AuditItem:
    id: int
    category: str          # "Governance", "Token Economy", "Repository Hygiene"
    requirement: str       # human-readable check description
    status: str            # "PASS" | "FAIL" | "WARN" | "SKIP"
    details: str           # what was found
    impact: str            # "CRITICAL" | "HIGH" | "MEDIUM" | "LOW"
    fixable: bool          # True if forge conform can auto-fix

@dataclass
class AuditReport:
    project_path: Path
    items: list[AuditItem]
    timestamp: str

    @property
    def compliance_rate(self) -> float: ...  # PASS / total * 100
    @property
    def fixable_count(self) -> int: ...
```

### Engine

`AuditEngine(project_path).run() -> AuditReport` — discovers project structure, runs each checker, returns report. Deterministic, zero-LLM.

## Phase 2: Audit Checks (`core/audit_checks.py`)

Each check: `(project_path: Path) -> AuditItem`. 15 checks total:

### Governance Core (4)
1. **G01_AGENTS_MD_EXISTS** — AGENTS.md exists in root or governance/
2. **G02_AGENTS_MD_LANGUAGE** — Content primarily English (<20% PT-BR patterns)
3. **G03_IDE_POINTERS** — CLAUDE.md/GEMINI.md exist with @AGENTS.md pointer
4. **G04_AGENTS_MD_GENERIC** — Root AGENTS.md has no tool-specific operational specs

### Execution Directives (5)
5. **G05_THINKING_CONSTRAINT** — "Thinking constraint" or "compact English" present
6. **G06_EXECUTION_LIMIT** — "3 to 5" step limit present
7. **G07_OUTPUT_FORMAT** — "Silent executor" present
8. **G08_BASH_RULE** — "tail/grep" or "pipe" bash rule present
9. **G09_GRAPH_FIRST** — "graph" or "code-review-graph" present

### Token Economy (2)
10. **G10_CONTEXT_BUDGET** — All AGENTS.md <1500 tokens (reuse context_linter)
11. **G11_SKILLS_FRONTMATTER** — SKILL.md descriptions single-line, ≤20 words

### Repository Hygiene (3)
12. **G12_GITIGNORE** — .gitignore has node_modules/, lockfiles
13. **G13_GITATTRIBUTES** — .gitattributes with `* text=auto eol=lf`
14. **G14_NO_DUPLICATES** — No file duplicates between componentes/ and .agents/

### Cache Invariance (1)
15. **G15_CACHE_PREFIX** — No timestamps or absolute OS paths in AGENTS.md

## Phase 4: Conform Engine (`core/conform_engine.py`)

```python
class ConformEngine:
    def __init__(self, project_path: Path, audit_report: AuditReport | None = None): ...
    def run(self, dry_run: bool = False) -> ConformReport: ...
```

Runs audit first (if not provided), filters fixable items, applies fixers with backup+rollback.

## Phase 5: Conform Fixers (`core/conform_fixers.py`)

| Audit ID | Fixer | Action |
|----------|-------|--------|
| G01 | `fix_agents_md_missing` | Create minimal AGENTS.md from template |
| G03 | `fix_ide_pointers` | Create CLAUDE.md with pointer, remove from .gitignore |
| G05-G09 | `fix_directives` | Append missing directives (marker-injection pattern) |
| G12 | `fix_gitignore` | Add missing patterns |
| G13 | `fix_gitattributes` | Create .gitattributes with LF |

Non-fixable (SKIP): G02 (language requires human), G10 (budget requires rewriting), G15 (requires review)

## Phase 6: CLI Integration

```
forge audit [PATH] [--format json|md|html] [--output FILE]
forge conform [PATH] [--dry-run] [--item ID]
```

- `audit`: exit 0 if compliance ≥ 80%, else 1
- `conform`: always runs audit first, prints ConformReport
