# Comando /master

Adiciona uma nova fatia vertical de negócio modular (`Vertical Slice`) ao `aidd-master`.

## Uso:
`/master <modulo>`

## Ação:
Executa a skill `skills/aidd-master-runner` para gerar rotas, serviços, modelos, testes e interface.
Equivalente CLI: `python ecossistema.py master add-module <modulo>`
