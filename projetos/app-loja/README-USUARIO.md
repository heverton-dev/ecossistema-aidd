# App Loja — como usar

## 1. Instalar (uma vez só)
No terminal, dentro desta pasta:
  python -m venv .venv
  .venv\Scripts\activate   (no Linux/Mac: source .venv/bin/activate)
  pip install -r requirements.txt
  cd frontend && npm install && cd ..
