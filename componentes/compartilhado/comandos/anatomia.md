# Comando /anatomia

> **Ação:** Executa a skill `aidd-anatomy` para dissecar minuciosamente qualquer alvo do ecossistema (ferramenta, pipeline ou componente).

Investiga o código real e documentação do alvo (grafo -> docs -> implementação -> ecossistema) e gera os artefatos de anatomia técnica estruturados em Markdown e HTML visual.

## Uso:
`/anatomia <nome-do-alvo>`

## Artefatos Gerados:
- `docs/anatomias/anatomia-<alvo>/anatomia-v1-<alvo>.md`
- `docs/anatomias/anatomia-<alvo>/anatomia-v1-<alvo>.html`
